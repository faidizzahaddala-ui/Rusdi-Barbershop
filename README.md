# POS Syariah - Rusdi Barbershop

Sistem Point of Sale (POS) modern yang dirancang khusus untuk memenuhi standar profesionalisme dan nilai-nilai Syariah.

## 🌿 Prinsip Amanah
Proyek ini dikembangkan dengan memegang teguh prinsip:
> *"Tunaikanlah amanah kepada orang yang mempercayaimu."*

Kami menggunakan standar kualitas tinggi melalui bantuan teknologi **AI (Gemini)** untuk memastikan kode yang bersih, desain premium, dan fungsionalitas yang akurat sesuai dengan kaidah amanah.

## 🚀 Fitur Utama
- **Autentikasi Aman**: Login dan Registrasi vendor terintegrasi dengan **Supabase**.
- **Kasir Cerdas**: Pengelolaan transaksi cepat dengan antarmuka modern.
- **Kalkulasi Zakat**: Perhitungan Zakat Niaga (2.5%) otomatis pada setiap transaksi.
- **Navigasi Mulus**: Pengalaman Single Page Application (SPA).

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS.
- **Backend**: Supabase (Auth & Database).
- **Deployment**: Vercel.
